# Sistema de Gestión y Cobranzas

Aplicación web interactiva desarrollada para la gestión y registro de repartos, cálculo de cobranzas con persistencia de datos y consumo de APIs/JSON local.

## 🚀 Funcionalidades principales

- **Ingreso de usuarios**: validación de credenciales habilitadas con temporizador de reintento.
- **Guía de ayuda**: Información sobre la función que cumple cada item del menú. 
- **Gestión de registros**: creación, modificación y eliminación de registros.
- **Cálculo dinámico**: cálculo de recargos según el método de pago seleccionado.
- **Persistencia**: almacenamiento de datos en `localStorage`.
- **Carga asincrónica**: consumo de datos mediante `fetch` desde archivos JSON / APIs.

## 🛠️ Tecnologías utilizadas

- **HTML5**: estructura semántica.
- **CSS3**: estilos y diseño responsivo.
- **JavaScript (ES6+)**: manipulación del DOM, eventos, asincronismo (`fetch`, Promesas, `async/await`) y almacenamiento local.
- **SweetAlert**: ventanas emergentes y alertas estilizadas para interacciones con el usuario.
